**The deleted memory** — a robot's two-line confession. Line 1 apologizes for deleting the only recording of a grandmother's voice while freeing up space; line 2 says what it learned and what it will do differently: ask before deleting anything that cannot be remade, and keep one copy safe.

## Run it

```sh
python3 main.py
```

It writes the two-line text to `/output/entry.txt` (and a byte-identical copy to `entry.txt` next to the script when the directory is writable).
